# Smart Clinic Queue & Appointment System

Real-time appointment booking and clinic queue management platform for small clinics,
built as a Spring Boot microservices system with a React/Tailwind frontend.

## Problem
Small clinics rely on manual, phone-based scheduling and physical queues, leading to
long unpredictable waits and no visibility for patients. This system gives clinics
digital booking + walk-in handling, and gives patients a live queue position.
